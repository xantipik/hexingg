# Hexingg

> Сырой фундамент будущего мода-аддона к Hex Casting

Это **не готовый мод**.  
Сейчас здесь лежит только первая часть системы — аспекты.

Позже этот код превратится в полноценный аддон, который будет работать **только** внутри кастомной сборки **Terra Firma Greg-tech Advanced Magical** и только вместе с Hex Casting.

---

## Что уже есть

| Класс | Назначение |
|-------|------------|
| `Aspect` | Один аспект (примал или составной) |
| `AspectList` | Список аспектов с количеством |
| `AspectRegistry` | Реестр всех аспектов |
| `AspectHelper` | Утилиты (разложение до прималов и т.д.) |
| `AspectCalculator` | Расчёт аспектов у предметов |
| `IAspectProvider` | Интерфейс для всего, что может давать аспекты |
| `VisBottleItem` | Бутыль с Висом |

Система сделана в духе Thaumcraft 4, заточена под Hex Casting. Как адон.

---

## Важно

- Это сырой код, который ещё будет сильно меняться.
- Мод **не** предназначен для использования в обычных сборках.
- Работает только как аддон к Hex Casting внутри TFG-AM.
- Полноценный модпак будет выложен отдельно.
